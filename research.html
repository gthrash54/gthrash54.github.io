Walker Lab: decoding the subthalamic nucleus

UAB Neurology · Dr. Harrison Walker · 2026 – present · planned dissertation laboratory

Intraoperative recordings from the subthalamic nucleus and cortex during deep brain stimulation surgery, made while patients rest, move, and speak. The goal is to decode behavioral state from these signals well enough to drive adaptive stimulation, and to understand how directional stimulation changes speech and movement. Methods: spectral and time-frequency analysis of local field potentials, band-power and phase-amplitude features, permutation statistics, and supervised decoders trained on labeled task windows.

Tools I build

  • Open source · MIT · active

    AnalyzeLFPs

    A desktop-hosted web app for intraoperative DBS and ECoG recordings. It reads TDT, BrainVision, and EDF data through one reader, describes each recording in a hand-curated manifest, gates every analysis behind a signed human QC review, and runs recipes for spectra, band-power contrasts with permutation tests, time-frequency, phase-amplitude coupling, event-locked averages, and ERNA. Thirteen guardrails check each run before anything is computed. Nothing leaves the machine.

    It ships with a 46-lesson graduate-level curriculum on the mathematics behind the analysis, from linear algebra and DSP to spike sorting and directional leads, as paired student and solution notebooks.

    RepositoryCurriculum
  • Pipeline · in use

    DBS recording inventory and derivatives

    A staging toolchain for a multi-case intraoperative dataset: verifies every raw file is readable, builds an inventory of leads, contacts, and streams per case, derives condition labels and task states, computes audio coherence and video motion traces for behavioral alignment, and writes de-identified derivatives to a separate store. Raw data and the identity crosswalk never leave the acquisition machine.

    Python · private data, code on request
  • Pipeline · in use

    AI-assisted evidence screening

    A hybrid title-and-abstract screening pipeline for large systematic and scoping reviews. A language model votes on every record with a confidence and exclusion code; high-confidence exclusions are removed only after both human reviewers validate a random sample against a pre-declared error threshold; the model then acts as second reviewer on the retained set, with humans deciding every disagreement. Follows the 2025 Cochrane/Campbell/JBI/CEE position statement and RAISE recommendations.

    Python · Anthropic API · Covidence
